# قرآن کریم — Quran App

اپلیکیشن حرفه‌ای و آفلاین‌محور قرآن کریم برای Android، با تمرکز بر تجربه مطالعه مصحف، معماری قابل توسعه و پشتیبانی از امکانات قرآنی و حدیثی.

## Version

**1.1.1**

- Version Name: `1.1.1`
- Version Code: `111`

## وضعیت فعلی

- نمایش قرآن کریم به‌صورت آفلاین
- دیتابیس SQLite داخلی
- متن قرآن بر پایه Tanzil / عثمان‌طه
- مصحف ۶۰۴ صفحه‌ای مدینه
- نگاشت آیات به صفحات مصحف
- نمایش صفحات ۱ تا ۶۰۴
- حرکت بین صفحات با Swipe
- اسکرول عمودی
- پشتیبانی از Portrait و Landscape
- حالت روشن و تاریک
- ذخیره دائمی تنظیمات حالت نمایش
- فونت Amiri Quran
- پشتیبانی RTL برای متن عربی
- نمایش نام سوره
- نمایش شماره آیات
- معماری قابل توسعه برای امکانات آینده

## معماری داده

دیتابیس داخلی شامل جداول اصلی زیر است:

- `surahs`
- `ayahs`
- `translations`
- `ayah_translations`
- `pages`
- `ayah_pages`

رابطه `ayah_pages` برای نگاشت آیات به صفحات مصحف استفاده می‌شود.

## مصحف

ساختار فعلی بر اساس مصحف ۶۰۴ صفحه‌ای مدینه طراحی شده است.

- صفحه‌بندی ۱ تا ۶۰۴
- اتصال آیات به صفحات مربوطه
- نمایش نام سوره
- نمایش شماره آیه
- متن عربی با RTL
- حرکت صفحه‌ای با Swipe
- اسکرول عمودی
- پشتیبانی از حالت تاریک و روشن

## فونت

برای نمایش متن قرآن از فونت **Amiri Quran** استفاده شده است.

فایل فونت:

`app/src/main/assets/fonts/AmiriQuran.ttf`

مجوز فونت:

`app/src/main/assets/fonts/OFL.txt`

## ساخت APK

پروژه برای Build مستقیم در Termux طراحی شده است.

فرآیند ساخت:

`javac → d8 → aapt2 → zipalign → apksigner`

ساخت APK:

`./build-app.sh`

خروجی:

`app/build/app-debug.apk`
